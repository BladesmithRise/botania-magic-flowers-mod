Harness the power of flowers to generate mana, automate tasks, and craft powerful magical equipment.

![Botania — Nature Magic Mod Preview](https://cdn.modrinth.com/data/pfjLUfGv/e40d77bf0245907048fb71b5a64ec3de10099ef1_96.webp)

## Features

- Mana-based magic system powered entirely by flowers
- Hundreds of functional flowers for automation and defense
- Terrasteel, Elementium, and Manasteel equipment tiers
- Elven Portal to the Alfheim dimension for endgame content
- Fully vanilla-style — no power cables or GUIs

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
